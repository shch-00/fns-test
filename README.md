# Vacancy Application Manager

## Описание проекта
Приложение для создания, отображения и редактирования заявок на размещение вакансий. Реализовано с использованием React и Formik для удобной работы с формами, а также Yup для валидации.

## Функциональность
- 📌 **Создание заявки** — форма с валидацией.
- 📌 **Отображение списка заявок** — загруженные данные отображаются в виде списка.
- 📌 **Редактирование заявки** — возможность обновлять данные существующей заявки.
- 📌 **Валидация форм** — ошибки отображаются под соответствующими полями.
- 🎨 **Опционально**: стилизация селекта и DatePicker.

## Технический стек
- ⚛ **React + Hooks**
- 📜 **Formik + Yup** (для валидации форм)
- 📂 **Mock JSON / аналог** (хранение данных)

## Установка и запуск
```bash
# 1. Клонируем репозиторий
git clone https://github.com/your-username/vacancy-app.git
cd vacancy-app

# 2. Устанавливаем зависимости
npm install

# 3. Запускаем локальный сервер
npm start
```

## Использование
1. Перейдите в браузер по адресу `http://localhost:3000`.
2. Добавьте новую заявку через форму.
3. Посмотрите список заявок.
4. Нажмите «Редактировать», чтобы изменить заявку.
